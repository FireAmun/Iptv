# Cinema appearance implementation plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task. Preserve the owner's existing in-place branch preference.

**Goal:** Apply approved Cinema A with saved dark/light appearance to the working phone and TV app.

**Architecture:** Shared colour/type tokens in a small Android Compose design-system module, device-specific Material adapters and layouts. App owns a nonsecret appearance preference and AppCompat night mode; data and playback engines remain unchanged.

**Tech Stack:** Kotlin, Compose Material 3, Compose for TV, AppCompat, Media3.

**Spec:** [Cinema design](../specs/2026-10-25-cinema-design.md).

## Global constraints

minSdk 28, compile/target 36, existing pinned dependencies. Dark is default. No invented catalogue/EPG data or inert tabs. Preserve URL redaction, per-operation HTTP approval, English/Arabic and RTL. One local emulator at a time; no firewall/driver/reboot changes. Develop on a separate branch while PR #3 runs, then integrate that PR first; deliver this slice through its own reviewed PR and complete latest-head CI.
