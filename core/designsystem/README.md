# Cinema design system

Shared palette, bilingual type and original source-setup illustration. Material adapters live with each device UI. [Approved design](../../docs/superpowers/specs/2026-10-25-cinema-design.md).

Bundled fonts from the official Google Fonts repository: [Manrope](https://github.com/google/fonts/tree/main/ofl/manrope) and [Cairo](https://github.com/google/fonts/tree/main/ofl/cairo). Downloaded 25 October 2026. Original OFL notices are in `licenses/` and packaged in `src/main/assets/licenses/`. Font binaries are bundled for offline rendering; no font service is contacted at runtime.
